## 🚀 快速开始

### 1. 安装浏览器扩展

```bash
# 克隆项目
git clone https://github.com/yourusername/wenpai.git

# 进入目录
cd wenpai

# 安装依赖
npm install

# 构建扩展
npm run build

# 加载扩展到Chrome
# 1. 打开 chrome://extensions/
# 2. 开启"开发者模式"
# 3. 点击"加载已解压的扩展程序"
# 4. 选择 dist 目录
```

### 2. 使用Web应用

访问 [https://www.wenpai.xyz](https://www.wenpai.xyz) 开始使用

## 🛠️ 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite
- **UI组件**: shadcn/ui + Tailwind CSS
- **状态管理**: Zustand
- **路由**: React Router v6
- **AI集成**: OpenAI API
- **浏览器扩展**: Chrome Extension Manifest V3
