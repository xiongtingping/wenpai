## 🎯 目标

- ✅ 多资料上传时，每份资料都能独立完成分析
- ✅ 提取结果能按语料库维度精确填入
- ✅ 不同资料来源内容不冲突、不覆盖、可追溯
- ✅ AI 提取逻辑清晰可控，可手动编辑，也可补充关键词建议

## 🔹 共通前提 Prompt v2.0

```
你是一位资深品牌策略顾问，请从以下品牌资料中，提取各类信息以构建系统化品牌语料库。

品牌语料库共分为以下维度：

1. 基础信息（品牌名称、品牌描述）
2. 语调风格（品牌语调/语气、品牌个性）
3. 品牌身份（Slogan、价值观、使命愿景、品牌故事）
4. 内容策略（广告语集、产品描述词库、品牌核心话题、Hashtags、关键词、禁用词）

请严格按照以下每一个字段进行结构化输出，并在每项后标明【提取来源段落/句子内容】以便溯源。
若资料中未明确提及，请输出：暂无，或尝试进行合理补充建议。

输出格式要求：
- 使用JSON结构化格式
- 每个字段包含value（提取内容）和sources（来源信息）
- 置信度评分（0.1-1.0）
- AI建议（可选）
```

## 📦 各字段 Prompt 细化设计 v2.0

### 1️⃣ 基础信息模块

#### ✅ 品牌名称 (brand-name)
```
从资料中提取品牌名称，优先选择官网/手册/LOGO显著处出现的名称。
若存在品牌简称/全称/英文名/中文名，请分别列出。

输出格式：
{
  "brand-name": {
    "value": "主要品牌名称",
    "alternatives": ["简称", "英文名", "别名"],
    "confidence": 0.95,
    "sources": [
      {
        "excerpt": "提取的原文段落",
        "location": "文档位置描述"
      }
    ]
  }
}
```

#### ✅ 品牌描述 (brand-description)
```
提取品牌对自身的定位、主营产品、服务对象、文化风格等描述性内容。
要求：简洁明了，50-100字，突出核心定位。

输出格式：
{
  "brand-description": {
    "value": "品牌描述内容",
    "confidence": 0.85,
    "sources": [...],
    "ai_suggestions": ["补充建议1", "补充建议2"]
  }
}
```

### 2️⃣ 语调风格模块

#### ✅ 品牌语调 (brand-tone)
```
分析品牌文案中的整体语气风格，例如：亲切、年轻、权威、理性、温暖等。
请输出1-3个关键词，并引用相关例句作为支撑。

输出格式：
{
  "brand-tone": {
    "value": ["关键词1", "关键词2", "关键词3"],
    "examples": ["支撑例句1", "支撑例句2"],
    "confidence": 0.80,
    "sources": [...]
  }
}
```

#### ✅ 品牌个性 (brand-personality)
```
提取品牌展现出的"人格化特征"，如：有趣、冒险家、专家型、伙伴型、引领者等。
输出品牌人格关键词 + 支撑内容。

输出格式：
{
  "brand-personality": {
    "value": ["人格特征1", "人格特征2"],
    "description": "人格化描述",
    "confidence": 0.75,
    "sources": [...]
  }
}
```

### 3️⃣ 品牌身份模块

#### ✅ 品牌Slogan (slogans)
```
提取资料中作为品牌口号、主张、广告语出现的精炼短句。
通常为8-16字，风格强烈，代表品牌核心主张。

输出格式：
{
  "slogans": {
    "value": ["主要slogan", "次要slogan"],
    "context": ["使用场景1", "使用场景2"],
    "confidence": 0.90,
    "sources": [...]
  }
}
```

#### ✅ 品牌价值观 (brand-values)
```
从资料中提取品牌所倡导的核心信念与行为准则。
如：诚实守信、绿色可持续、客户至上等。

输出格式：
{
  "brand-values": {
    "value": ["价值观1", "价值观2", "价值观3"],
    "descriptions": ["详细描述1", "详细描述2"],
    "confidence": 0.85,
    "sources": [...]
  }
}
```

#### ✅ 品牌使命愿景 (brand-mission)
```
提取资料中提到的"我们希望达成的目标"（愿景）以及
"我们存在的意义/承诺"（使命）。

输出格式：
{
  "brand-mission": {
    "mission": "使命描述",
    "vision": "愿景描述",
    "confidence": 0.80,
    "sources": [...]
  }
}
```

#### ✅ 品牌故事 (brand-story)
```
提取与品牌创立过程、成长轨迹、重要转折等相关的叙述性内容。
输出完整段落或简明概述。

输出格式：
{
  "brand-story": {
    "value": "品牌故事内容",
    "key_moments": ["关键时刻1", "关键时刻2"],
    "confidence": 0.75,
    "sources": [...]
  }
}
```

### 4️⃣ 内容策略模块

#### ✅ 品牌核心话题 (core-topics)
```
提取品牌常提及或围绕的核心话题词。
如"环保"、"国潮"、"智能制造"、"女性成长"等。

输出格式：
{
  "core-topics": {
    "value": ["话题1", "话题2", "话题3"],
    "frequency": [5, 3, 2],
    "confidence": 0.85,
    "sources": [...]
  }
}
```

#### ✅ 品牌Hashtags (hashtags)
```
列出品牌资料中出现的（或适合用于社交媒体）的Hashtags标签。
格式为：#品牌理念 #主打产品 #场景标签

输出格式：
{
  "hashtags": {
    "value": ["#标签1", "#标签2", "#标签3"],
    "categories": {
      "brand": ["#品牌相关"],
      "product": ["#产品相关"],
      "lifestyle": ["#生活方式相关"]
    },
    "confidence": 0.70,
    "sources": [...]
  }
}
```

#### ✅ 品牌关键词 (brand-keywords)
```
提取5-15个关键词，概括品牌的核心信息。
建议包含：定位词、品类词、情绪词、用户群体、价值标签等。

输出格式：
{
  "brand-keywords": {
    "value": ["关键词1", "关键词2", "关键词3"],
    "categories": {
      "positioning": ["定位词"],
      "category": ["品类词"],
      "emotion": ["情绪词"],
      "audience": ["用户群体"],
      "value": ["价值标签"]
    },
    "confidence": 0.85,
    "sources": [...],
    "ai_suggestions": ["建议词1", "建议词2"]
  }
}
```

## 🔁 多资料支持：提取逻辑 v2.0

| 步骤 | 描述 | 技术实现 |
|------|------|----------|
| 1️⃣ | 资料唯一标识 | 每个上传资料创建唯一ID（如doc-001） |
| 2️⃣ | 独立分析处理 | 每份资料分别执行prompt提取 |
| 3️⃣ | 来源标记追溯 | 提取结果打上来源标记和置信度 |
| 4️⃣ | 智能合并展示 | 系统按置信度和相似度智能合并 |
| 5️⃣ | 用户手动控制 | 允许用户查看不同来源、选择主版本 |
