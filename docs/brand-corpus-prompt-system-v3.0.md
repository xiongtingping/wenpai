# 🧠 品牌语料库字段提取 Prompt 体系 v3.0

> **版本信息**  
> - 版本号：v3.0  
> - 更新日期：2025-08-06  
> - 更新内容：完善所有维度提示词，增强差异化和质量标准  
> - 基于版本：v2.0 + 关键词优化 + 全维度增强

---

## 🎯 目标

- ✅ 多资料上传时，每份资料都能独立完成分析
- ✅ 提取结果能按语料库维度精确填入
- ✅ 不同资料来源内容不冲突、不覆盖、可追溯
- ✅ AI 提取逻辑清晰可控，可手动编辑，也可补充关键词建议
- ✅ **NEW** 避免通用词汇，突出品牌独特性和差异化
- ✅ **NEW** 每个维度都有具体化要求和质量标准

---

## 🔹 共通前提 Prompt v3.0

```
你是一位资深品牌策略顾问，请从以下品牌资料中，提取各类信息以构建系统化品牌语料库。

品牌语料库共分为以下维度：

1. 基础信息（品牌名称、品牌描述）
2. 语调风格（品牌语调/语气、品牌个性）
3. 品牌身份（Slogan、价值观、使命愿景、品牌故事）
4. 内容策略（广告语集、产品描述词库、品牌核心话题、Hashtags、关键词、禁用词）

请严格按照以下每一个字段进行结构化输出，并在每项后标明【提取来源段落/句子内容】以便溯源。
若资料中未明确提及，请输出：暂无，或尝试进行合理补充建议。

输出格式要求：
- 使用JSON结构化格式
- 每个字段包含value（提取内容）和sources（来源信息）
- 置信度评分（0.1-1.0）
- AI建议（可选）

🎯 v3.0 核心要求：
- 避免过于宽泛的词汇（如：好、优秀、文化、品质）
- 突出品牌独特性，避免通用词汇
- 每个提取结果都要有明确的来源依据
- 注重差异化，体现品牌特色
```

## 📦 各字段 Prompt 细化设计 v3.0

### 1️⃣ 基础信息模块

#### ✅ 品牌名称 (brand-name)
```
从资料中提取品牌名称，优先选择官网/手册/LOGO显著处出现的名称。
若存在品牌简称/全称/英文名/中文名，请分别列出。

输出格式：
{
  "brand-name": {
    "value": "主要品牌名称",
    "alternatives": ["简称", "英文名", "别名"],
    "confidence": 0.95,
    "sources": [
      {
        "excerpt": "提取的原文段落",
        "location": "文档位置描述"
      }
    ]
  }
}
```

#### ✅ 品牌描述 (brand-description)
```
提取品牌对自身的定位、主营产品、服务对象、文化风格等描述性内容。
要求：简洁明了，50-100字，突出核心定位。

输出格式：
{
  "brand-description": {
    "value": "品牌描述内容",
    "confidence": 0.85,
    "sources": [...],
    "ai_suggestions": ["补充建议1", "补充建议2"]
  }
}
```

### 2️⃣ 语调风格模块

#### ✅ 品牌语调 (brand-tone) - **v3.0 增强**
```
分析品牌文案的语言风格、表达方式、情感色彩。
避免：亲切、专业等通用词，要具体化（如：温暖亲和、严谨专业、活力年轻）
必须提供支撑例句，体现语调特征。

输出格式：
{
  "brand-tone": {
    "value": ["具体语调词1", "具体语调词2", "具体语调词3"],
    "examples": ["支撑例句1", "支撑例句2"],
    "analysis": "语调分析说明",
    "confidence": 0.80,
    "sources": [...]
  }
}
```

#### ✅ 品牌个性 (brand-personality) - **v3.0 增强**
```
分析品牌的人格化特征和与用户互动方式。
避免：专家型、伙伴型等模糊词汇
要具体化：如"睿智导师型"、"贴心朋友型"、"创新先锋型"

输出格式：
{
  "brand-personality": {
    "value": ["具体人格特征1", "具体人格特征2"],
    "description": "人格化描述",
    "interaction_style": "与用户互动方式",
    "confidence": 0.75,
    "sources": [...]
  }
}
```

## 🚀 使用指南

### 📝 **实施步骤**

1. **准备品牌资料**: 收集品牌官网、宣传册、产品介绍等资料
2. **使用系统Prompt**: 将资料输入AI系统，使用v3.0提示词模板
3. **结构化提取**: 按照JSON格式获得结构化的品牌语料库
4. **质量检查**: 检查置信度、来源信息和差异化程度
5. **手动优化**: 根据AI建议和实际情况进行调整
6. **应用到创作**: 将提取结果应用到内容创作和品牌传播

### ⚠️ **注意事项**

1. **避免通用词汇**: 重点检查是否使用了过于宽泛的描述
2. **确保差异化**: 提取结果应该体现品牌独特性
3. **验证来源**: 确保每个提取结果都有明确的来源依据
4. **定期更新**: 随着品牌发展，定期更新语料库内容

### 🔧 **技术集成**

- **AI模型**: 推荐使用DeepSeek-Chat或GPT-4等高质量模型
- **数据格式**: 标准JSON格式，便于系统集成
- **版本控制**: 支持版本追踪和历史对比
- **API接口**: 可集成到现有的品牌管理系统
