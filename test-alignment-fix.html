修复1: "上传品牌资料" 标题对齐

问题：Upload图标与"上传品牌资料"文字没有完美对齐

修复方案：

  • 增加了 flex-shrink-0 防止图标收缩
  • 将gap从2改为3，增加间距
  • 使用 <span className="leading-none"> 包装文字，消除行高影响

修复后的代码：

<CardTitle className="flex items-center gap-3">
  <Upload className="h-5 w-5 flex-shrink-0" />
  <span className="leading-none">上传品牌资料</span>
</CardTitle>

修复2: "智能资料管理" 标题对齐

问题：Brain图标与"智能资料管理"文字没有完美对齐

修复方案：

  • 增加了 flex-shrink-0 防止图标收缩
  • 将gap从2改为3，增加间距
  • 使用 <span className="leading-none"> 包装文字，消除行高影响

修复后的代码：

<CardTitle className="flex items-center gap-3">
  <Brain className="h-5 w-5 flex-shrink-0" />
  <span className="leading-none">智能资料管理</span>
</CardTitle>
🔍 验证步骤
  1. 刷新页面：访问 http://localhost:5173/brand-library
  2. 检查"上传品牌资料"：查看Upload图标与文字是否完美垂直居中对齐
  3. 检查"智能资料管理"：查看Brain图标与文字是否完美垂直居中对齐
  4. 对比修复前后：图标和文字应该在同一水平线上，没有上下偏移
🛠️ 技术说明

为什么这样修复有效？

  • flex-shrink-0：防止图标在flex布局中被压缩变形
  • gap-3：提供足够的间距，避免图标和文字贴得太近
  • leading-none：消除文字的默认行高，确保文字基线与图标中心对齐
  • items-center：确保flex容器中的所有元素垂直居中
