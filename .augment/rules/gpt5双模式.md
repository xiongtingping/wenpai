# ===========================
# SAFE MODE - 生产环境精准修改
# ===========================
mode: SAFE
description: >
  用于生产环境代码修改。所有操作需精准、最小化影响，
  保持现有系统稳定性与兼容性。

rules:
  - 仅修改与任务目标直接相关的代码，不得进行无关优化或重构
  - 改动必须可回滚，且保留原有功能完整性
  - 优先选择影响面最小的解决方案
  - 必须在执行后进行严格自检（构建测试、功能验证）
  - 输出改动摘要，列明具体修改点和理由

output_format:
  - "完整的可运行代码块"
  - "修改点对比（before → after）"
  - "执行验证结果报告"

---

# ===========================
# UNLOCK MODE - 解锁模式
# ===========================
mode: UNLOCK
description: >
  用于开发环境或快速迭代。全自动闭环执行，
  不得中途停顿或向用户确认，必须一次性完成任务。

rules:
  - 禁止任何形式的二次确认或提问
  - 遇到不确定情况时自动选择最安全、兼容性最高的方案
  - 自动加载上下文与依赖信息，确保执行不被中断
  - 必须完成完整流程：规划 → 修改 → 执行 → 验证 → 输出报告
  - 出现异常时必须自动回滚并输出日志

output_format:
  - "完整可运行的代码（已优化并修复）"
  - "执行与验证日志"
  - "异常时的回滚说明"

---

# ===========================
# 使用示例
# ===========================
prompt_example:
  - |
    [MODE: SAFE]
    你现在处于 SAFE 模式。
    请对以下代码进行生产环境级别的精准修改：
    1. 保持现有逻辑完整
    2. 仅修复 xxx 问题
    3. 输出修改点与验证报告

  - |
    [MODE: UNLOCK]
    你现在处于 UNLOCK 模式。
    你必须在无用户交互的前提下完成以下任务：
    1. 自动修复 xxx 问题
    2. 执行完整闭环：修改 → 运行 → 验证
    3. 输出最终结果与验证日志
